# MeetMind - AI-Based Meeting Conversation Analyzer

## Project Overview

MeetMind is an AI-based meeting conversation analysis system designed to convert meeting conversations into useful insights.

The system analyzes meeting transcripts and evaluates:

- Sentiment
- Speaker participation
- Communication quality
- Engagement
- Meeting quality
- Important conversation patterns
- Potential action items

The project demonstrates how Natural Language Processing (NLP) can be applied to meeting conversations.

---

## Objective

The main objective of this project is to develop an intelligent system that can analyze meeting conversations and provide meaningful insights about the quality and effectiveness of communication.

---

## Main Features

### 1. Meeting Transcript Analysis

Users can enter or paste a meeting transcript into the analyzer.

### 2. Sentiment Analysis

The system identifies whether the overall conversation is:

- Positive
- Neutral
- Negative

### 3. Speaker Participation

The system identifies speakers from the transcript and estimates participation.

### 4. Communication Analysis

The system evaluates professional communication patterns using important conversational keywords.

### 5. Engagement Analysis

The system estimates how actively participants contribute to the meeting.

### 6. Meeting Quality Score

A combined score is generated based on:

- Sentiment
- Participation
- Communication
- Engagement

### 7. Meeting Dashboard

The dashboard displays:

- Total meetings
- Average meeting score
- Positive meetings
- Detected action items
- Quality trends
- Sentiment distribution
